# Chickens Game
Este proyecto esta inspirado en chickens game un juego tipo arcade el cual quise reconstruir con nuevas funcionalidades.

## Modo de ejecucion
Para crear el entorno virtual
```bash
python -m venv venv
```
Para activar el entorno virtual
-  CMD:
```bash
.venv/Scripts/activate.bat
```

-  PowerShell:
```bash
.venv/Scripts/activate.ps1
```

## Ejecucion
Desde la raiz del proyecto ejecutar
```bash
py -m src.view.menu-view
```
